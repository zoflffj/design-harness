# 허들링 서비스 유저스토리

출처: [허들링 앱 PRD](PRD.md)

PRD의 주요 시연 대상인 유료 멤버를 기준으로 정리한다.

| 구분 | 유저스토리 | PRD 근거 |
|---|---|---|
| 1 | 유료 멤버가 홈에서 이번 달 미션과 자신의 진행 상황을 확인한다. | §5 홈 |
| 2 | 유료 멤버가 스킬 라이브러리에서 검증된 프롬프트와 스킬 파일을 탐색한다. | §5 스킬 라이브러리 |
| 3 | 유료 멤버가 미션 결과물을 제출하고 피드백을 받아 수정한다. | §3 시나리오 2 |
| 4 | 유료 멤버가 승인된 산출물을 내 자산으로 전환하고 선택적으로 판매를 신청한다. | §3 시나리오 2 |
| 5 | 유료 멤버가 허들링 픽에서 다른 멤버의 검증된 자산을 탐색하고 선택적으로 구매한다. | §3 시나리오 3 |

## 이 서비스에서 어기면 안 되는 것

| 원칙 | PRD 근거 |
|---|---|
| 무료·유료·판매용 자료를 명확히 구분하고 회원 등급별 접근 권한을 지킨다. | §7 권한 구조, §11 평가 기준 1 |
| 자산 마켓은 검수형으로 운영하며 완전 오픈마켓으로 운영하지 않는다. | §4 허들링 픽, §12 제외 사항 |

## 시연 범위 유의사항

구매는 PRD에 있는 사용자 시나리오이지만, 결제·정산 구현은 시연 범위에서 제외되어 있다(§12).
